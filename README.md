# Pong Game

A classic Pong game built with HTML5, CSS3, and JavaScript.

## Features

✅ **Player Control**: Left paddle controlled by arrow keys (↑/↓) or mouse movement
✅ **Computer AI**: Right paddle automatically tracks the ball
✅ **Bouncing Ball**: Physics-based ball movement with collision detection
✅ **Scoreboard**: Real-time score tracking for both player and computer
✅ **Collision Detection**: 
   - Ball bounces off top/bottom walls
   - Ball bounces off paddles with spin based on hit position
   - Speed increases slightly with each paddle hit (up to max speed)
✅ **Win Condition**: First to 11 points wins
✅ **Visual Effects**: Neon glow effects, gradient backgrounds, smooth animations

## How to Play

1. Open `index.html` in your web browser
2. Use **Arrow Keys (↑/↓)** or **Mouse Movement** to control the left paddle
3. Try to defeat the computer AI by getting the ball past its paddle
4. First player to score 11 points wins!

## Controls

- **Arrow Up (↑)**: Move paddle up
- **Arrow Down (↓)**: Move paddle down
- **Mouse**: Move paddle up/down automatically

## Game Rules

- The ball bounces off the top and bottom walls
- Players score when the opponent fails to hit the ball
- The first player to reach 11 points wins
- Ball speed increases with each paddle hit (up to a maximum)
- Ball spin is affected by where it hits the paddle

## Files

- `index.html` - Main HTML file
- `styles.css` - Styling and animations
- `script.js` - Game logic and physics

## Browser Compatibility

Works on all modern browsers that support HTML5 Canvas (Chrome, Firefox, Safari, Edge, etc.)
